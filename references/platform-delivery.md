# 离线 H5 交付易错点

本页是开发经验摘要，不代替官方文档。相关公开文档曾在 2026-10-22 核验，使用时重新查询当前版本。

## 包、资源与兼容性

- ZIP 根目录直接有唯一 index.html，不多套一层项目目录。只打包运行文件，不打包 node_modules、Git 数据、源映射、测试截图或 SDK 密钥。
- 脚本外置且使用经典 script；用 addEventListener 绑定事件，不使用内联脚本、行内事件、module 或动态执行。资源全部包内相对引用，不能依赖 CDN。
- 当前已知规范以 Chrome 61 / ES2017 为兼容基线。可选链、对象展开等需转译；无需构建链时直接写兼容语法。普通语法检查只验证当前 Node 能解析，不证明旧 WebView 可解析。
- Flex 的 gap 不可作为唯一布局路径，使用 margin 等回退；safe-area 先有普通值，再使用平台变量/env 增强；表单、弹层和核心按钮应能在小屏幕触摸使用。
- 本地预检建议值：ZIP 不超过 2 MiB，上限 10 MiB；大 Base64、大源码和大数据集需按官方 skill 人工核对。压缩率不代表运行时内存。

## 图片与存储

选图使用用户主动触发的 input[type=file]。图片可用 data: 或 blob: 预览，对象 URL 使用后释放；保存图片优先用文档公开的 saveImageToPhotosAlbum，必要时先 writeTempFile。文件路径使用平台返回句柄，不自行猜测端上路径。失败时提供真实提示。

优先使用适用于目标版本的平台缓存；版本未知或低于门槛才使用带异常处理的浏览器存储降级。平台缓存写入失败不能显示成功。不同缓存方案之间需要迁移规则，迁移成功前保留旧稿。数据都可能被清理，重要图纸允许导出。

## 上传表单与测试

名称、简介、版本、图标和封面按当前上传页限制准备。图标和封面上传要求可能变动，以页面为准。模板只使用相册与本地草稿，不需要摄像头或麦克风；用户新增能力后再调整权限。

交付清晰区分：

- 静态预检：结构、资源、语法风格、常见禁用能力、体积。
- 本地回归：算法、交互、模拟 CSP 和模拟平台接口。
- 平台验收：创服模拟器、Android 扫码和 iOS 扫码。没有运行证据就标「待验证」。

发布按钮报「无可提审的开发包」时检查代码 ZIP 是否上传并部署成功，再检查当前版本是否绑定成功。只选图标/封面或勾选权限不能创建开发包。
